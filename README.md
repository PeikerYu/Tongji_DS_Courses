## 关于

这里汇总了我在同济大学数据科学与大数据技术专业学习期间整理的课程资料。各门课程独立维护，本仓库提供统一导航，方便查找笔记、作业、报告与项目。

**目前收录 9 个课程相关仓库，随学习进度持续补充。** 目录仅列出已有资料，具体收录范围见各仓库 README。
